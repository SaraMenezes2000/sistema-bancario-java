# Sistema Bancário em Java

Sistema bancário desenvolvido em Java como projeto de estudo,
acompanhando um tutorial e realizando adaptações e melhorias
para praticar os conceitos aprendidos.

## Tecnologias

- Java
- Programação Orientada a Objetos
- Git
- GitHub

## Funcionalidades

- Criação de conta
- Depósito
- Saque
- Consulta de saldo
- Transferências

## Objetivo

Projeto desenvolvido para praticar lógica de programação,
Programação Orientada a Objetos e conceitos fundamentais de Java.
